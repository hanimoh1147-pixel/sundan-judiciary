أرشيف القضايا السودانية — النسخة المطوّرة
=========================================

محتويات الحزمة:
- index.html: واجهة الموقع العربية.
- style.css: تصميم متجاوب للهواتف والحواسيب.
- app.js: البحث والفلاتر والخط الزمني.
- README.txt: تعليمات النشر.

تشغيل محلي:
1) فك ضغط الحزمة.
2) افتح index.html في متصفح حديث.
3) يحتاج الخط الخارجي إلى اتصال إنترنت، لكن الموقع يعمل أيضًا بخط بديل عند عدم توفره.

النشر العام المجاني على GitHub Pages:
1) أنشئ مستودعًا عامًا جديدًا في GitHub.
2) ارفع الملفات الثلاثة index.html وstyle.css وapp.js إلى جذر المستودع.
3) افتح Settings ثم Pages.
4) اختر Deploy from a branch، ثم الفرع main والمجلد /(root)، ثم Save.
5) انتظر بناء الموقع، وافتح رابط Pages الذي يظهر في صفحة الإعدادات.

ملاحظات التوثيق:
- النسخة الحالية هي أساس للموقع وليست أرشيفًا شاملاً لكل القضايا في كل السنوات.
- المداخل الموجودة تشير إلى مصادر أو عناوين منشورة، وبعضها معلّم بأنه يحتاج مراجعة النص الأصلي.
- قبل كتابة أي رواية كاملة: تحقّق من نص الحكم، والمحكمة، والتاريخ، ورقم الدعوى إن توفر، ومسار الاستئناف/النقض، والنص القانوني المطبق وقت الواقعة.
- لا تنشر اتهامات غير محسومة كأنها إدانة، واحجب البيانات الشخصية الحساسة، واحترم حقوق النشر.
- لا توجد لوحة تحكم أو قاعدة بيانات في هذه النسخة؛ تحديث المداخل يتم من ملف app.js. يمكن تطويرها لاحقًا إلى نظام إدارة محتوى وقاعدة بيانات.
